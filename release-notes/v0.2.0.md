**Setup just got a lot easier.** CouchCord now walks you through its one-time Discord setup instead of asking you to edit a JSON file.

## What's new

- **First-run setup wizard** — on first launch, CouchCord opens a setup screen: a button straight to the Discord Developer Portal, paste boxes for your application's Client ID and Client Secret with inline validation, and a **Save & Start** that writes the config and relaunches into the overlay. No file editing, no guessing where the config lives (the screen shows you).
- Clearer first-run errors: a corrupt or hand-edited-wrong `config.json` reports exactly what's wrong instead of failing silently.

Everything else is v0.1.0: the corner HUD with speaking rings, the Back + Start panel with mute/deafen/disconnect, and the server → channel switcher — see the [v0.1.0 notes](https://github.com/MyNamesEMurray/CouchCord/releases/tag/v0.1.0) for the full tour.

## Setup (still one-time, now guided)

1. Install and launch — the setup screen opens.
2. Click through to the Developer Portal, create a **New Application**, copy the **Client ID** and **Client Secret** from its OAuth2 page, paste, **Save & Start**.
3. Click **Authorize** in the Discord popup. Done — the grant is cached.

Windows SmartScreen will warn on first run (unsigned build): *More info → Run anyway*.
