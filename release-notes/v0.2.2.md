Fixes the authorization failure v0.2.1 uncovered: **`invalid_request: missing "redirect_uri"`**.

## The fix

Discord now requires a `redirect_uri` in RPC authorization requests, which the RPC library never sends. CouchCord now performs the authorization handshake itself and includes `redirect_uri` where Discord expects it.

**This adds one small step to the one-time setup**: your Discord application must have that redirect registered.

> On your app's **OAuth2** page, under **Redirects**, click **Add Redirect**, enter exactly
>
> `http://127.0.0.1`
>
> and **Save Changes**.

The setup wizard, error dialog, and README all walk through it now.

## If you're upgrading from v0.2.1

1. Add the redirect above to your existing Discord application (no need to recreate it).
2. Install this build and launch — click **Authorize** once in Discord.
3. The CouchCord panel opens when authorization succeeds. You're done.

Also in this build: token refresh no longer depends on the RPC library's OAuth internals at all, making the cached-grant path (silent startup after the first run) more robust.
