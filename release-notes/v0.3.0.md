Two additions from the couch: **remap the summon chord from the panel**, and **server icons in the channel browser**.

## New

- **Remap Chord (learn mode)** — a new panel button. Hold the button combo you want on the controller, keep it held for one second, and it becomes the summon chord: saved to `config.json`, active immediately, no restart. The panel footer always shows the current chord (e.g. *Hold LB + RB to close*), Esc cancels, and learn mode times out after 20 seconds if nothing is captured. Single buttons and up-to-any-size combos both work — the hold-to-summon delay still guards against accidental triggers in-game.
- **Server icons** — the Voice Channels browser now shows each server's icon (with a colored-initial fallback for servers without one).

## Notes

Requires the working v0.2.4 base (authorization + transport fixes) — if you're on anything older, this build includes all of that too.
