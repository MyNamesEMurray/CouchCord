The first release of **CouchCord** — a controller-summoned Discord voice overlay for couch gaming on Windows HTPCs.

Your game runs borderless-fullscreen from Big Picture; CouchCord floats a click-through HUD in the corner showing who's in voice and who's talking. Hold **Back + Start** on the controller and a 10-foot panel opens: mute, deafen, hop to any voice channel on any of your servers, or disconnect — all with the d-pad. Close it and the game gets your controller back.

## Highlights

- **Passive HUD** — channel members with live speaking rings, mute/deafen flags; appears in voice, hides when you leave, never steals focus.
- **Controller summon** — Back + Start held ~400 ms, working while the game has focus. Xbox, PlayStation, Switch Pro, and most generic pads (hot-plug supported); button hints match your pad's labels (✕/○ vs A/B).
- **Voice control from the couch** — mute · deafen · disconnect · a server → channel switcher covering every server you're in.
- **Companion, not a client** — talks to your running Discord desktop app over local RPC (the StreamKit mechanism). No user tokens, no HTTP API.
- Config file for chord, HUD corner, scale, and launch-on-login; automatic reconnect when Discord restarts.

## Setup

1. Run the installer (per-user, no admin). Windows SmartScreen will warn — the build is unsigned; choose *More info → Run anyway*.
2. Create your (free, personal) Discord application and put its Client ID + Secret in `config.json` — first launch shows the path and the [README](https://github.com/MyNamesEMurray/CouchCord#discord-setup-one-time-2-minutes) walks through it (~2 minutes, one time).
3. Keep the Discord desktop app running, join a voice channel, and play.

**Limitation by design:** borderless/windowed games only — no overlay over exclusive fullscreen (CouchCord does no injection or game hooking).
