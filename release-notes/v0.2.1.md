Fixes the first-run experience reported in the wild: the Discord **Authorize popup no longer loops forever**, and CouchCord now shows itself after setup instead of sitting invisible.

## Fixed

- **Endless authorize popups** — if anything went wrong after clicking *Authorize* (wrong Client Secret, Discord logged into a different account than the one that owns your application, a rejected scope), CouchCord silently retried the whole authorization and re-opened the popup forever. It now asks **at most once per launch**; on failure you get an error dialog with the exact Discord error and the likely causes, plus **Try again**, **Redo setup** (reopens the wizard), and **Quit**.
- **Invisible first run** — after a successful authorization the panel now opens automatically, so you can see CouchCord running. (After that, the HUD appears only while you're in a voice channel — that part is by design.)

## Added

- **`couchcord.log`** — every run writes timestamped diagnostics next to `config.json` (`%APPDATA%\CouchCord`). If anything misbehaves, that file is what to paste into an issue.

## If v0.2.0 looped on you

Install this build and launch again. If authorization still fails, the dialog will now tell you why — the two most common causes:

1. The Discord **desktop app** is logged into a **different account** than the one that owns your Discord application. They must match — an unapproved application only works for its owner.
2. The **Client Secret** was pasted wrong — on your app's OAuth2 page click **Reset Secret**, copy the new value, and use the dialog's *Redo setup* button.
