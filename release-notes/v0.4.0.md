A **Settings menu** in the overlay, and chord learning that's cancellable from the couch.

## New

- **Settings view** — a new panel menu (replacing the standalone Hide HUD button) with couch-editable settings, each cycling with **A** and saved to `config.json` instantly:
  - **Summon chord** (the learn mode from v0.3.0)
  - **Chord hold time** — 250 / 400 / 600 / 800 ms
  - **HUD corner** — all four corners
  - **Overlay size** — 80–200 %, applied live
  - **Show HUD in voice** — on/off
  - **Launch on login** — on/off
- **Chord learning is cancellable from the controller**: hold **B/○ alone** for a second to back out (B still works inside multi-button combos). The learn screen and hints say so.

## Fixed

- **Esc now reliably cancels chord learning** — it's registered as a system-wide shortcut while learn mode is active, so it works even if the overlay window isn't the focused window.
