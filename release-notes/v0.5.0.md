HUD appearance settings, and a fix for the clipped drop shadow.

## Fixed

- **Clipped drop shadow** — the overlay window hugged the card so tightly that its shadow was cut off at the window edge. The window now carries transparent padding on all sides, so the shadow fades out naturally (and the window sits correspondingly closer to the screen corner — the visible position barely changes).

## New — HUD appearance in Settings

Two new rows in the panel's Settings view, both saved instantly:

- **HUD style** — *Everyone* (the classic list), *Compact* (names only, tighter rows, speakers highlighted in mint), or *Speaking only* (rows appear only while someone talks — the most minimal in-game footprint).
- **HUD opacity** — 50 / 65 / 85 / 95 %. Applies to the corner HUD only; the interactive panel stays opaque so menus remain readable over gameplay.
